# Week 3 – Unsupervised Learning and Clustering Analysis

## Project Overview

This project focuses on customer segmentation using unsupervised machine learning techniques.

The objective is to identify groups of customers with similar characteristics based on:

- Age
- Annual Income
- Spending Score

## Dataset

The project uses the Mall Customers dataset containing 200 customer records.

## Methodology

1. Load and inspect the dataset
2. Check missing values and duplicates
3. Select relevant clustering features
4. Remove CustomerID from the clustering features
5. Standardize the numerical features
6. Use the Elbow Method
7. Use Silhouette Analysis
8. Apply K-Means Clustering
9. Apply Hierarchical Clustering
10. Visualize and interpret customer segments
11. Analyze business implications

## Algorithms Used

- K-Means Clustering
- Hierarchical/Agglomerative Clustering

## Evaluation

The clustering approach is evaluated using:

- Elbow Method
- Silhouette Score

## Business Objective

The discovered customer segments can help businesses understand different customer profiles and develop more targeted marketing strategies.

## Files

- `Week_3_Clustering_Analysis.ipynb` – Complete analysis and code
- `Mall_Customers.csv` – Dataset
- `Week_3_Clustering_Analysis_Beautiful_Colorful_Bullet_Final.docx` – Detailed project report

## Conclusion

The project demonstrates how unsupervised learning can be used to discover meaningful customer groups from demographic and spending-related information.
